## Version 1.4.2
**Warning: Before installing this version, make sure to back up your previous configurations.**

- 🔧 Fixed
  - Client crash caused by null sound in `PlaySoundEvent`.
- ✅ Added
  - Now you can add mobs to hear TACZ & VPB Guns in only 1 config `gun_fire_mobs`

